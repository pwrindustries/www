// Features

Octet TFTP 1.2
Speed & progress

Fast transfers you can watch

Octet negotiates bigger blocks with devices that support it, about 3× faster than classic 512-byte TFTP. Every transfer gets its own bar with percent, size, speed and time left. Older devices still work the classic way.

Safe uploads

A failed upload never touches your file

Uploads land in a hidden temporary file and replace the original only when the last block arrives. If a device drops mid-transfer, your existing config stays exactly as it was and nothing half-written is left behind.

Allowed devices

Only the gear you expect

Limit the server to single addresses or ranges such as 10.1.1.0/24. Anything else gets “Access denied”, and every refusal is written to the log. The list is saved between launches.

Menu bar mode

Keeps serving with the window closed

The “8” icon shows at a glance whether the server is stopped, running or transferring. Start and stop, flip GET and PUT, see your IP and check recent transfers right from the menu bar.

// Quick setup

Under a minute

Pick a folder

Click Choose… and select the folder with your images and configs.

Allow GET / PUT

Turn on downloads, uploads, or both.

Start the server

Octet shows your Mac’s LAN IP and port 69.

Copy from the device

Point the device at your Mac’s IP and go.

! Cisco IOS-XE, Mac at 192.168.1.50 (lab addressing)
lab-sw1# copy tftp://192.168.1.50/c9300-17.15.06.bin flash:
lab-sw1# copy running-config tftp://192.168.1.50/lab-sw1-config.txt
! Management port or VRF? Pick the source interface first:
lab-sw1(config)# ip tftp source-interface GigabitEthernet0/0

// FAQ

Do I need an admin password for port 69?

Not with Octet TFTP. On current macOS, it opens UDP port 69 directly, with no helper, no Terminal and no password. Octet Lite opens port 69 directly where macOS allows it, and otherwise falls back to a small admin helper that may ask for your admin password.

The device can ping my Mac, but the copy times out

Something between them is blocking TFTP. Between subnets, allow UDP 69 to your Mac plus the high UDP ports the transfer uses, or use a firewall with a TFTP helper. Check the Mac firewall and the device’s route back. The easy fix is putting your Mac on the same VLAN. More in Support →

What’s the difference between Lite and Octet TFTP?

Octet Lite (1.0.2) is the free, basic server: port 69, GET/PUT switches, folder picker and log. Octet TFTP adds faster transfers, progress bars, safe uploads, allowed devices and menu bar mode, and it installs and updates through the Mac App Store.

Does Octet collect any data?

No. There are no accounts, no analytics and no tracking. Files move only between your Mac and your own devices. Read the privacy policy →
