Octet release notes

Every Octet release, newest first: what was fixed and what changed. Get the latest build on the Octet download card.

Octet 1.2.0

October 11, 2026 Latest

New

  • Faster transfers. Octet now supports TFTP option negotiation (block size, transfer size and timeout, RFC 2347, 2348 and 2349). Devices that ask for bigger blocks get them, and transfers run about 3× faster than classic 512-byte TFTP. Devices that don’t support options still work the classic way.
  • Live progress bars. Every active transfer gets its own bar showing the percent, amount moved, speed and time left. When the size isn’t known, a moving bar shows the amount so far. Finished transfers turn green, and failed ones turn red.
  • Safe uploads. Uploads are written to a hidden temporary file and swapped in only once the last block arrives. A failed or aborted upload never damages the existing file or leaves a partial one behind, and any leftover temporary files are cleaned up automatically.
  • Allowed devices. Limit the server to specific IP addresses or ranges such as 10.1.1.0/24, with an on/off switch. Devices not on the list get “Access denied”, every refusal is logged, and the list is saved between launches.
  • Menu bar mode. A new “Transfer 8” icon shows at a glance whether the server is stopped, running or transferring. From the menu you can start and stop the server, flip the download and upload switches, see your IP address and check recent transfers. Octet keeps serving when the window is closed.
  • Window size. The window always opens at a comfortable size with the transfer log visible.

Fixes

  • The menu bar now shows the correct port.
  • Octet no longer uses high CPU while running in menu bar mode.

Requires macOS 14 or later on a Mac with Apple silicon. On 1.0.2, Octet will offer this update on its own. On 1.0.0 or 1.0.1, download it once by hand.

Octet 1.0.2

October 9, 2026

New

  • Update check. When it opens, Octet checks for a newer version (at most once a day). If one is out, a bar at the top of the window says so, with Download and Release notes buttons. You can also check any time from Octet > Check for Updates… in the menu bar. Octet never installs anything on its own. You download the new version and drag it into Applications, and the bar goes away once you’re up to date.

If you’re on 1.0.0 or 1.0.1, download this version once by hand. From 1.0.2 on, Octet will tell you when there’s an update.

Octet 1.0.1

October 9, 2026

Fixes

  • File transfers work again. In 1.0.0, every download and upload timed out because the server never sent its replies. A security change that locks each transfer to the client’s address caused it. Transfers now finish normally, and the lock is still in place.
  • The Allow downloads and Allow uploads switches always show their real state. Before, they turned gray whenever the Octet window wasn’t in front, so they looked off even when they were on.

Octet 1.0.0

October 9, 2026

Initial release

  • Pick a folder and serve it over TFTP on port 69.
  • Optional admin helper so Octet can use port 69 without running the whole app as root.
  • Separate Allow downloads and Allow uploads switches, so you control exactly what clients can do.
  • Live transfer log, with export to a text file.
  • Signed and notarized by Apple. Built for Macs with Apple silicon.

Known issue: transfers time out. Fixed in 1.0.1.
